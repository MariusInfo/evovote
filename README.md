Votifier integration and reward system for **Minecraft Forge 1.20.1**.

## Features
- **Automated Votifier Listener:** Listens for incoming server votes and executes rewards.
- **Configurable Rewards:** Set custom vote URL, reward key identifier, and key amounts via config/evovote-common.toml.
- **Broadcast & Sliding GUI Notifications:** Displays announcements and sliding GUI notifications on vote.
- **Periodic Reminders:** Sends periodic clickable voting reminders in chat.

## Commands
| Command | Permission | Description |
| :--- | :--- | :--- |
| /vote | Everyone | Displays clickable voting link and reward info |
| /adminvote <player> | OP / Console | Triggers vote delivery manually |

## Requirements
- Minecraft Forge **1.20.1** (47.4.18+)
- Java **17**
- **EvoCore** 1.0.0+
